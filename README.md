# Medilink Appointment Platform
Online appointment-management platform for small medical and dental clinics.

## Development Workflow
Backlog -> REady -> In Progress -> Code Review -> Verification -> Done
WIP Limit: 3 concurrent items across In Progress + code Review combined.

## Using the templates
Choose a bug report or feature request template when opening an issue. When opening a pull request, use the PR template to link the issue, summarize changes, describe testing, and verify the Definition of Done.
